# POSIX shell in Python

### It supports the execution of the following commands:
- echo
- exit
- type
- pwd
- cd
- cat

### Features
- **echo** : Prints the provided string to the standard output.
- **exit**: Exits the shell.
- **type**: Displays information about command type.
- **pwd**: Prints the current working directory.
- **cd**: Changes the current directory.
- **cat**: Concatenates and displays the content of files.
### Installation and Setup
Clone the repository:
```
git clone https://github.com/tanmayagrwl/Posix-shell.git
```
Navigate to the project directory:
```
cd Posix-shell
```
Run the shell:
```
python main.py
```
